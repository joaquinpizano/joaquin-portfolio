# Joaquin Pizano | AI & Business Analytics Portfolio

**[Visit My Live Portfolio](https://joaquin-pizano.vercel.app)**

I'm a University of South Florida student studying Artificial Intelligence and Business Analytics. This portfolio showcases independent projects exploring how data, analytics, and technology can help solve real-world business problems.

## Featured Projects

### PharmaOpt | Pharmaceutical Analytics

An experimental decision-support application exploring pharmaceutical supply challenges, historical data, and resource allocation.

[View Project](https://joaquin-pizano.vercel.app/projects/pharmaopt) | [Try PharmaOpt](https://pharmaopt.streamlit.app)

### RiskMap | Flood Risk & Insurance Analytics

An insurance analytics project combining historical NFIP claims, provisional insured exposure, and FEMA geographic flood-hazard context to support further risk analysis.

[View Project](https://joaquin-pizano.vercel.app/projects/riskmap) | [GitHub Repository](https://github.com/joaquinpizano/RiskMap)

## Technology Stack

- **Frontend:** Next.js, React, TypeScript
- **Deployment:** Vercel
- **Analytics projects:** Python, SQL, Streamlit, Tableau, Excel

## Run Locally

Requires Node.js 22 LTS.

```bash
npm ci
npm run dev
```

Open http://localhost:3000.

To validate the application:

```bash
npm run typecheck
npm run build
```
